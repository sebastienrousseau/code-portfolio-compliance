# Comparison

The matrix this tool checks is defined only in `~/Code/AGENTS.md` (§5) and
`~/Code/REPO-STANDARD.md`. No other tool implements it, so there is nothing
to compare signal for signal. General repository-health tools, such as
OpenSSF Scorecard, score their own criteria against a hosted repository;
none of their results is used here, and no claim is made about how they
compare.
